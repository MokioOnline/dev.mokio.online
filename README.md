# Mokio website

Static site for GitHub Pages.

## Pages
- `index.html` home
- `music.html` music player
- `messages.html` messaging

## Host on GitHub
1. Create a repo
2. Upload every file in this folder
3. Settings → Pages → Deploy from branch `main` / root
4. If the custom domain is `mokio.online`, keep the `CNAME` file

Messages uses your existing Supabase project. Music plays files you pick on your computer.
