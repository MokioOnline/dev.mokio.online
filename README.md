# Mokio Dev — dev.mokio.online

## Who can see this site
Only accounts whose profiles.role in Supabase is one of:
- tester
- mod
- dev
- owner

Everyone else is blocked.

current/

  styles.css
  script.js
  ...any other files

When an allowed user signs in, they are taken straight into current/dev.html.
